# Gökdoğan Intelligence v1.0.0 — GitHub Yayın Metni

## İlk resmî sürüm

Gökdoğan Intelligence v1.0.0; kamuya açık veya operatörün kullanım yetkisine sahip olduğu OSINT/canlı veri kaynaklarını Türkçe, harita tabanlı bir Windows masaüstü çalışma alanında birleştiren ilk resmî sürümdür.

### Öne çıkanlar

- harita tabanlı küresel/bölgesel durum farkındalığı
- sivil/ticari hava ve deniz gözlemleri
- kamu verisindeki askerî hava aracı/reference sınıflandırmaları
- kamu kamera/CCTV katalog entegrasyonları
- afet, yangın, deprem, yanardağ ve hava olayları
- haber ve diplomasi akışları
- uydu/uzay katmanları
- trafik/sınır ve altyapı katmanları
- piyasa göstergeleri
- yerel API anahtar yönetimi ve kaynak sağlığı
- Tauri/Rust masaüstü kabuğu + FastAPI/Python backend + Next.js/TypeScript frontend

### Kurulum

Windows kullanıcıları Release varlıklarındaki installer'ı indirip SHA-256 değerini doğrulayabilir. Kaynaktan build için `START-HERE.bat` kullanılabilir.

### Önemli not

Gökdoğan, kapalı sistemlere erişim kontrolü aşmak için tasarlanmamıştır. Özel/kapalı kamera erişimi, kişi hedefli gizli takip veya hassas askerî hedefleme kamu sürümünün kapsamı dışındadır. Üçüncü taraf verileri gecikmeli veya geçici olarak çevrimdışı olabilir.

### Lisans

Kaynak kod AGPL-3.0 altındadır. Üçüncü taraf veri sağlayıcıların kendi lisans ve kullanım şartları ayrıca geçerlidir.
