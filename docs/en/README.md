## Localization scope

The repository, community workflow and core user documentation support both Turkish and English. The Windows desktop application remains Turkish-first in v1.0.0. New user-facing strings should be localization-ready so full English UI localization can expand without maintaining a separate code fork.

## Responsible-use summary

Gökdoğan Intelligence is intended for public or properly authorized sources. It must not be used to bypass access controls, discover private camera systems, expose credentials, conduct person-targeted surveillance, evade law enforcement, or facilitate operationally sensitive targeting.
