## Current localization scope

The repository and community workflow support both Turkish and English. The Windows desktop application remains Turkish-first in v1.0.0. New user-facing strings should be localization-ready so English UI localization can expand without maintaining a separate code fork.

## Detailed technical documentation

The most detailed installation, user-guide, provider-reference, troubleshooting and legal/responsible-use documents currently remain under the Turkish [`docs/`](../) directory. English translations should preserve the same responsible-use boundaries and provider attribution requirements.

## Responsible-use summary

Gökdoğan Intelligence is intended for public or properly authorized sources. It must not be used to bypass access controls, discover private camera systems, expose credentials, conduct person-targeted surveillance or facilitate operationally sensitive targeting.
