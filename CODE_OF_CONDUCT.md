# Davranış Kuralları

**Türkçe** | [English](CODE_OF_CONDUCT.en.md)

Gökdoğan Intelligence topluluğunda teknik yeterlilik kadar saygılı ve güvenli iletişim de önemlidir.

## Beklenen davranışlar

- İnsanlara ve farklı görüşlere saygılı yaklaşın.
- Eleştiriyi kişiye değil teknik konuya yöneltin.
- Hata raporlarında mümkün olduğunca tekrar üretilebilir bilgi sağlayın.
- Güvenlik veya mahremiyet riski oluşturabilecek ayrıntıları herkese açık kanallarda paylaşmayın.
- Yeni veri kaynaklarının lisans, kullanım koşulları ve mahremiyet sınırlarına dikkat edin.
- Kullanıcıları yasa dışı erişim, gizli veri toplama veya zararlı kullanım yönünde teşvik etmeyin.

## Kabul edilmeyen davranışlar

- taciz, tehdit, nefret söylemi veya kişisel saldırı,
- doxxing veya kişisel bilgilerin izinsiz paylaşılması,
- API anahtarı, parola, token veya başka gizli bilgilerin yayımlanması,
- kapalı/özel sistemlere izinsiz erişim talebi veya yönlendirmesi,
- hassas kişi, kolluk veya askerî hedeflerin operasyonel takibini kolaylaştıran içerik,
- spam veya projeyle ilgisiz reklam.

## Uygulama

Topluluk standartlarını ihlal eden içerikler silinebilir; kullanıcılar uyarılabilir, geçici veya kalıcı olarak proje iletişim alanlarından uzaklaştırılabilir.

Güvenlik açığı bildirimleri için `SECURITY.md` dosyasını kullanın. Genel hata ve özellik talepleri GitHub Issues üzerinden yapılmalıdır.
