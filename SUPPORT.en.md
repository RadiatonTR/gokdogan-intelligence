# ❤️ Support Gökdoğan Intelligence

Gökdoğan Intelligence is developed as a free and open-source project.

If the project is useful to you, you can support ongoing development, Windows releases, testing infrastructure, security maintenance, documentation, map performance and sustainable integrations with public/authorized data sources.

## First sponsorship goal

### 10 recurring monthly Gökdoğan Intelligence supporters

The first community goal is **10 recurring monthly sponsors**. Support is intended to make post-v1.0 maintenance and development more sustainable, especially for:

- Windows build and release infrastructure,
- code-signing and distribution costs,
- bug fixes and regression testing,
- security and dependency updates,
- public/authorized data-source integrations,
- map, cache and live-data performance,
- API/provider integration testing,
- Turkish and English documentation,
- long-term project maintenance.

> Sponsorship does not grant access to private, classified, access-controlled or otherwise unavailable data sources.

## Suggested monthly tiers

- **$3/month — Coffee Supporter**: a small contribution to ongoing development.
- **$5/month — Gökdoğan Supporter**: helps documentation, bug fixing and maintenance.
- **$10/month — Open Source Supporter**: supports public-data integrations, map layers and integration testing.
- **$25/month — Project Sponsor**: supports release automation, security maintenance and broader development work.
- **$50/month — Principal Supporter**: substantial support for long-term open-source sustainability.

Recognition may include an optional public thank-you, sponsor listing or general roadmap updates. Sponsorship does not purchase a feature, guarantee delivery or provide privileged data access.

## Access policy

Sponsorship never provides:

- access to private or closed camera systems,
- bypassed or unauthorized data sources,
- classified military or operational data,
- person-targeted private tracking systems,
- hidden capabilities unavailable to normal users,
- a right to bypass third-party API licenses or terms of service.

Gökdoğan Intelligence's public release should be used only with public data or sources you are authorized to access.
